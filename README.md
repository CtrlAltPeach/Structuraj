# Structuraj

Настольное приложение для разведки больших наборов JSON/JSONL: выбираешь папку —
получаешь единую структуру ключей по всем вложенным файлам сразу и можешь по любому
ключу листать, сортировать и фильтровать все его значения.

Только чтение. Исходные файлы не меняются никогда. Единственная запись на диск —
`STRUCTURE.md` в целевую папку по кнопке «Экспорт».

## Запуск

```bash
npm run tauri dev
```

Сборка установщика:

```bash
npm run tauri build
```

Тесты ядра:

```bash
cd src-tauri && cargo test
```

## Устройство в двух абзацах

**Rust (`src-tauri/src/`)** делает всю работу: обходит папку, потоково разбирает
JSON, складывает всё в одноразовый SQLite-индекс и отдаёт фронтенду готовые
страницы данных. Ни один мегабайт исходных файлов в вебвью не попадает.

**Фронт (`src/`)** — React 19 + TypeScript, только отрисовка. Вся связь с Rust
собрана в `src/api.ts`.

| файл | зачем |
|---|---|
| `scan.rs` | обход папки, потоковый разбор JSON/JSONL, канонизация путей |
| `db.rs` | схема SQLite-индекса |
| `tree.rs` | сборка дерева структуры в двух режимах + экспорт в Markdown |
| `query.rs` | страницы значений, список записей, чтение записи из файла |
| `lib.rs` | команды Tauri — граница с фронтом |

## Ключевая идея

Индексы массивов схлопываются в `[]`, поэтому одинаковые ключи из разных файлов и
разных элементов массива попадают в один узел автоматически:

```
$[].user.name      ← name всех пользователей во всех файлах
$[].items[].sku    ← sku всех позиций всех заказов
```

Подробности — в [ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Где что лежит

* Индекс: `%LOCALAPPDATA%\com.structuraj.app\index.sqlite`, пересоздаётся при каждом скане
* Артефакты сборки Rust: по умолчанию `src-tauri/target/`. Если проект лежит в синхронизируемой папке (OneDrive и подобные), скопируй `src-tauri/.cargo/config.toml.example` в `config.toml` и укажи каталог вне неё — иначе облако станет синхронизировать десятки гигабайт объектных файлов

## Тесты

Фикстуры в `src-tauri/tests/fixtures/` покрывают массив объектов, JSONL, одиночный
объект, всегда пустые ключи и заведомо битый файл. Класть туда что-то ещё нельзя:
папка сканируется целиком, любой лишний файл сдвинет счётчики.

Два служебных прогона (запускать вручную):

```bash
cd src-tauri && cargo test --test pipeline -- --ignored --nocapture
```

Кладут в `src-tauri/tests/samples/` файлы `STRUCTURE-BY-NAME.md`,
`STRUCTURE-BY-PATH.md` и `API-SAMPLES.json` — чтобы глазами посмотреть форматы.
